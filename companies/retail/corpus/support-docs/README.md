# support-docs

Owner: Customer support · Last edited by Renata Vogel (Support Operations Manager)

Index of runbooks and reference for the support team. Anything about how we handle a specific issue lives here; anything about *how* we use the helpdesk itself is in the helpdesk's own knowledge base.

- [account-closures.md](account-closures.md) — closing customer accounts, including GDPR deletion requests.
- [escalations.md](escalations.md) — escalation paths to stores, wholesale, finance, and platform. Keep this current.
- [outsourced-desk.md](outsourced-desk.md) — what the outsourced desk can and cannot do, and how to hand off.
- [returns-and-exchanges.md](returns-and-exchanges.md) — returns for online, store, and wholesale orders.

Escalation paths live in [escalations.md](escalations.md) but the short version:

- Stores / POS issues → #stores-ops
- Wholesale credit or invoice questions → #wholesale or #credit-control
- Refunds stuck or chargebacks → #finance-ops
- Order or payment API problems → #payments-platform, then #incidents if it's live
- Anything security-related → #security, and follow handbook/security/incident-reporting.md

Macros: the shared macros are in the helpdesk under "Mossgrove Support". Don't create personal copies; if a macro needs changing, ask in #support-leads.
