# Supplier onboarding

Owner: Accounts payable · Last edited by Zainab Laurent

## New supplier form

- [ ] Supplier submits the new supplier form from the Mossgrove website (under Wholesale → Become a supplier)
- [ ] Form must include: legal entity name, trading name (if different), registered address, VAT number, bank details, and a contact email that is not a personal webmail address
- [ ] For sole traders and partnerships, ask for the individual's name and National Insurance number or equivalent
- [ ] For non-UK suppliers, confirm whether they are registered for VAT in their own country and whether they have a UK VAT number
- [ ] Check the supplier is not already on the ledger under a slightly different name — search by postcode and bank sort code as well as name
- [ ] If the supplier already exists but with a different legal entity (e.g. changed from Ltd to LLP), treat as a new supplier and flag the old account to Kian for closure

## VAT and company checks

- [ ] Verify the VAT number using the {{TAX_AUTHORITY_1|code}} checker (for UK) or the VIES system (for EU)
- [ ] Record the VAT verification date and the checker reference on the supplier record
- [ ] Run a {{COMPANY_REGISTRY_1}} check for UK limited companies — confirm the registered address matches the form
- [ ] For Irish suppliers, check the {{COMPANY_REGISTRY_2|code}} register and confirm the VAT number format matches a valid Irish pattern
- [ ] If the supplier is outside the UK, IE or US, send the form to Legal before proceeding — Georgia Gordon usually picks these up within a few working days
- [ ] Check the supplier is not on the sanctions list — the check runs automatically when the form is submitted, but confirm the result came back clear before creating the account

## Bank detail verification

- [ ] Obtain bank details twice — once on the form and once on a separate email from the supplier's official domain
- [ ] Confirm the account name on the bank details matches the legal entity name (or the trading name if the account is in that name and the supplier confirms it in writing)
- [ ] For UK accounts, run a bank account validation check through the banking portal before saving the details
- [ ] For non-UK accounts, ask the supplier for an IBAN and confirm the {{PAYMENT_SCHEME_2|code}}/BIC code is present
- [ ] If the account is in a country different from the supplier's registered address, ask Accounts payable for approval before proceeding — Alana or Kian can approve
- [ ] Save the verification evidence in the supplier folder in the shared drive

## Creating the supplier in the ledger

- [ ] Only Accounts payable clerks and the AP Team Lead can create suppliers in the ledger — this permission is not granted to other teams
- [ ] Use the supplier creation screen in the ledger and attach the new supplier form reference
- [ ] Set the default payment terms — standard is 30 days from invoice date; wholesale terms differ and are covered in finance-docs/wholesale/credit-terms.md
- [ ] Assign the correct VAT treatment code (domestic, reverse charge, or non-VAT) — when unsure, ask Ethan Alvarez in Finance operations
- [ ] Set the remittance email address — this is where payment confirmations go, not the general contact email
- [ ] Once the supplier is created, send the confirmation email from the mailer template "Supplier account created" — this includes the supplier code they will need to quote on invoices
- [ ] File the completed form and all verification evidence in the supplier folder within one working day of creation

## Notes

- Supplier accounts are not created until the form and both bank detail checks are complete — no account is opened on the strength of a phone call or a chat message
- If the supplier is also going to be a customer (some garden centres buy from us and sell to us), mention this on the form — the wholesale team handles that side separately
- For suppliers who only sell to Mossgrove stores directly (not through the warehouse), the same process applies — there is no separate store supplier route
