# Paying suppliers

> Needs updating after the move to the new AP queue — tell Nico Holm if something here looks wrong.

## New suppliers

- Ask the supplier for their invoice details: legal name, registered address, tax number, bank account and {{PAYMENT_SCHEME_2|code}}/BIC.
- Check the supplier is not already set up under a similar name — search the back office and the expenses tool before creating a new record.
- Add the supplier in the back office with the details from their letterhead, not from an email attachment. If the details come by email, ask them to confirm on headed paper.
- Set the payment terms to the default (30 days) unless the contract says otherwise. Net-7 is only for suppliers who are also Kilbarra customers.
- For suppliers outside the EEA, complete the additional fields in the back office (bank country, currency, any intermediary bank details).
- Assign a cost centre. If unsure, leave it blank and the approver on the invoice will pick it up.
- Tell the requester when the supplier record is live — usually within one working day.

## Coding invoices

- All invoices go through the back office queue. Scan them in on the working day they arrive; do not batch them up.
- Code the invoice to the cost centre and account code on the purchase order if there is one. If there is no PO, use the cost centre on the requisition email and ask the budget holder if it is not obvious.
- VAT must be coded separately. The back office will suggest the VAT code from the supplier record — change it if the invoice shows a different rate.
- Credit notes: code them against the same account and cost centre as the original invoice. If the original invoice was paid in a previous run, mark the credit note for offset against the next payment run.
- Attach the PO and any delivery note to the invoice record. Missing attachments will bounce the invoice back to the queue.

## Payment runs

- Supplier payments run twice a month — the first run covers invoices approved by the middle of the month, the second run covers the rest.
- The cut-off for including an invoice in a run is the working day before the run starts, mid-afternoon Dublin time.
- The treasury workstation pulls the approved invoices into the run. Review the list for duplicates and for any invoice that has already been paid — this happens more often than it should.
- Runs over EUR 250k in total need a second approver from the Payroll & payables team or the CFO office.
- Once the run has been approved, do not edit the payment list. If something is wrong, stop the run and start again.
- Foreign currency payments go through the treasury workstation's FX desk. The exchange rate is fixed at the time the run is submitted.

## Changes to bank details

- Only change a supplier's bank details after a phone call to the number on file. Ask the caller for the last four digits of their bank account and the amount of the last invoice we paid them.
- Do the call from a Kilbarra phone and log the call in the supplier record.
- If the supplier cannot answer the verification questions, do not change the details. Tell them to send a letter on headed paper and tell Nico Holm if they push back.
- Bank details changes are effective for the next payment run after the change is logged.
