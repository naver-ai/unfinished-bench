# Photo shoot checklist

Owner: Brand studio  
Last edited: Abel Carvalho

## Pre-shoot

- Confirm shoot date and location with the studio scheduler; check for clashes with store windows or wholesale catalogue deadlines.
- Book photographer and any assistants via the studio calendar; liaise with Dublin tech hub if the shoot involves product UI or app screens.
- Pull product list from the catalogue and confirm quantities with the merchandising team; flag any missing samples to the brand coordinator.
- Check the weather forecast for outdoor shoots; have an indoor fallback location noted in the shoot plan.
- Verify the rights tracker is up to date for all models, locations and props — see the rights tracker in the shared drive.
- Pack memory cards, batteries, lenses and the studio light kit; confirm the camera body and backup body are both charged.

## On the day

- Shoot the white-background hero shots first, then lifestyle and detail shots.
- Capture the required angles per the shot list: front, back, side, close-up of hardware/fabric texture, and scale reference if applicable.
- Log each product SKU against the frame numbers as you go; note any product defects on the shot list for retouch.
- Do a mid-shoot review of the first few frames with the photographer to confirm colour and exposure are consistent.
- If shooting in a store, coordinate with the store manager on opening times and keep the floor clear of customers during the shoot.

## After

- Upload raw files to the studio share in the `brand-studio` folder within one working day, organised by shoot date and product line.
- Select final images and note the selects list; hand off to the retoucher with colour notes and any defect fixes required.
- Confirm retouched files are exported at the correct size and resolution for web and print — check the asset spec sheet for dimensions.
- Add final images to the asset library and update the rights tracker with the shoot date, usage rights and any model release expiry.
- Send a short summary to the marketing team with the shoot highlights and any products that need a reshoot; flag delivery dates in the studio planner.
