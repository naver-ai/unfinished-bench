# Onboarding checklist (managers)

Owner: People team · Last edited by Leon Delgado

## Before day one

- Raise the laptop request in the helpdesk at least five working days before the start date. Choose the standard build unless the role has a specific need (call the IT team directly if in doubt).
- Submit access requests via the `tickets` system using the "New starter access" template. Include the role's standard system list from the handbook (`handbook/it/access-requests.md`). Add anything role-specific — wholesale roles usually need `sharectl` access to the wholesale price lists, finance roles need `ledgerctl` read-only to start.
- Assign a buddy from the same team (not their line manager). The buddy should be someone who has been in the team at least a few months and can answer the "where do I find" questions.
- Ask the buddy to book a coffee or lunch for the first day — the People team can expense this via the expenses tool under "Onboarding".
- Make sure the line manager has set up the first week's calendar: team intro, 1:1s, and the mandatory security induction (see `handbook/security/data-classification.md`).
- If the new starter is office-based in Leeds, Dublin, or Columbus, add them to the relevant chat channel (`#leeds-office`, `#dublin-office`, or the US channel — check with IT for the exact one). Wholesale staff get added to `#wholesale` too.
- Check the start date against the payroll calendar (`finance-docs/payroll/payroll-calendar.md`) so the first pay run is correct. If the start date falls after the payroll cut-off, tell the new starter when their first pay will land.

## First day

- Welcome them in the team channel and introduce them briefly in `#general` (no need for a long post — one or two lines is fine).
- Walk through the building basics: kitchen, toilets, bike storage, meeting room booking. For store staff, the store manager does this locally.
- Confirm they can sign in to their laptop and MFA is set up. If anything is missing, raise a `tickets` request marked "urgent onboarding".
- Point them to the handbook — especially `handbook/company/org-overview.md` and `handbook/comms/writing-to-customers.md` if their role touches customer comms.
- Check they are in the right chat channels. New starters should be in `#general`, their team channel, and any office channel. Add them to `#random` only if they ask — not everyone wants it.
- Schedule the 30-day check-in with them (line manager) — this is separate from the probation review in the HR system.

## First two weeks

- Book the store visit for office-based staff (Leeds, Dublin, Columbus, or Wakefield DC — pick the nearest). This is a half-day, usually in the second week. The store manager knows the drill; if not, contact `#stores-ops`.
- Wholesale staff: arrange a call or visit with someone from the wholesale team to walk through the credit terms and how `sharectl` is used for data sharing with partners (see `finance-docs/wholesale/credit-terms.md`).
- Finance roles: the Finance Operations team runs a short session on `ledgerctl` basics and the month-end close process (`finance-docs/month-end-close.md`). Ask Anders Fonseca's team to schedule it.
- Make sure they have done the mandatory data classification and security training (in the HR system). The People team tracks completion — if it's not done by the end of week two, the line manager gets a reminder.
- Check whether they need access to the analytics warehouse (most roles in buying, marketing, and finance do). If so, add it to the access request — see `eng-docs/data/warehouse.md` for the process.
- Set up the first performance conversation for around the six-to-eight week mark (not the formal review — just the informal check-in described in `handbook/people/performance-reviews.md`).

## Notes

- The buddy role is not optional — if the named buddy can't do it, pick another. Buddy should be someone who will actually be around in the first week.
- If the new starter is in a store, the store manager runs onboarding locally. The People team still handles the laptop and access requests — the store manager just needs to raise the helpdesk ticket with "store" in the title.
- For wholesale roles, check whether the new starter needs a company card for expenses — most wholesale account managers do. See `handbook/people/expenses.md` for how to request one.
- If anything in this checklist feels out of date, tell the People team — we'd rather fix it than have it linger.
