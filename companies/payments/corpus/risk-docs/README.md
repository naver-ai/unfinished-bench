# risk-docs

Risk & compliance documentation. Owner: Compliance. Last edited by Soren Hughes.

## What's here

- `aml/` — merchant due diligence (KYB), transaction monitoring
- `compliance/` — complaints, outsourcing register, regulatory change log
- `controls/` — control testing
- `privacy/` — data subject requests
- `risk/` — chargeback monitoring, merchant risk ratings

## Three lines of defence

Operations owns the first line (risk decisions in day-to-day business). Compliance and Risk oversee and challenge (second line), and Internal Audit provides independent assurance (third line) — see `handbook/company/org-overview.md` for the split.
