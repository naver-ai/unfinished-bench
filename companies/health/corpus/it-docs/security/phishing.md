# Phishing and reporting emails

**Owner:** Information security  
**Last edited by:** Kai Teixeira (Security Analyst)

## The report button

1. In the email client, click **Report message** in the toolbar (envelope with a flag icon). If you are on a mobile device, open the message and choose **More → Report message**.
2. If you are not sure a message is phishing but something feels off, report it anyway. Reporting a legitimate message is not a problem; not reporting a real one is.
3. The report button sends the full message headers and body to the security team. You do not need to forward anything or attach files.

## What happens after you report

- Security analysts review reported messages in batches, usually twice a day on working days.
- If the message is confirmed phishing, it is added to the blocklist and the mail filter is updated so the same sender or pattern is stopped at the gateway. If the message was sent to other people in the org, the security team posts in #security with a short note.
- You will not get a reply to every report. If the message was part of a wider campaign, the team may follow up with you directly through tickets or chat.

## Quarterly phishing exercises

- The security team runs a phishing exercise each quarter. Messages are sent from the exercise platform and look like common external emails (package delivery, document share, sign-in alerts).
- If you click a link in an exercise message, you will see a page explaining it was a test. No one gets in trouble for clicking. The exercise data is used to decide where additional training is needed.
- If you report an exercise message, that is the right behaviour and it is counted as a correct response.

## If you clicked a link or entered credentials

1. Do not close the browser or delete the email yet.
2. Use the **Report message** button on the original email.
3. If you entered your Kellsbrook password on the page, change your password at the sign-in portal right away. Then go to the security hub and start a password reset for the affected account.
4. If you entered a password on a page that was not the normal Kellsbrook sign-in page, call the service desk (option 2) so the account can be checked for unusual activity.
5. If you downloaded and opened an attachment, disconnect the device from the network (turn off Wi-Fi or unplug the cable) and call the service desk.

The service desk and the security team would rather get a report that turns out to be nothing than hear about a compromise later.
