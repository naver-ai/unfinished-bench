# Payroll calendar and cut-offs

**Owner:** Accounting, AP and payroll  
**Last edited by:** Jin Kowalski (Senior Accountant)

This document covers the monthly payroll runs for the Netherlands and the semi-monthly runs for the US, including cut-offs for changes, expenses, and overtime. The payroll provider handles both runs; we submit inputs through the payroll provider's portal and confirm totals by the cut-off times below.

If a cut-off falls on a non-working day, the cut-off moves to the previous working day. For US runs, cut-offs are in Denver time.

## Netherlands monthly payroll

Payroll closes on the last working day of the month. The holiday allowance is paid in one run — the May payroll — rather than accrued monthly. Any changes to salary, allowances, or deductions must be submitted by the cut-off for the month they apply to; changes received after that go into the following run.

| Item | Cut-off | Notes |
|---|---|---|
| Contract and salary changes (HR system) | 3 working days before run close | Includes new hires, terminations, and rate changes |
| Overtime and field allowances (field app) | 2 working days before run close | Field technicians log hours in the field app; the sensor network team reviews and approves before this cut-off |
| Expense reimbursements (expenses tool) | 2 working days before run close | Expenses submitted after this are paid in the next run |
| Adjustments from payroll provider review | 1 working day before run close | Payroll provider sends a pre-run review; we confirm totals by this time |
| Payday | Last working day of the month | Salary is paid via the payroll provider; payslips are available in the provider portal |

## US semi-monthly payroll

US payroll runs twice a month. The run period covers the working days up to the cut-off. Overtime for US field technicians is logged in the field app and must be approved by the sensor network team before the cut-off.

| Run | Cut-off | Payday |
|---|---|---|
| First run | 5th working day of the month | 3 working days after cut-off |
| Second run | Third-last working day of the month | Last working day of the month |

For the second run, contract and salary changes must be in the HR system by the cut-off. Changes received after the cut-off are processed in the first run of the following month. Expenses for the US office follow the same cut-offs as the payroll runs they are attached to.

## General notes

- Payroll calendar invitations are shared from the Accounting, AP and payroll team at the start of each financial year; they include the exact cut-off dates for all runs in that year.
- If you need to correct an input after the cut-off, contact Ebony, Bo, or Eleni in payroll directly — corrections are possible before the payroll provider finalises the run, but the later the change, the more likely it has to wait.
- The payroll provider portal has a read-only view for Accounting, AP and payroll; only the payroll administrators can submit files.
- For questions about overtime approval in the field app, the sensor network team owns the approval step; for expense policy questions, see the expenses page in the handbook.
