# Records centre

**Owner:** Records management  
**Last edited by:** Hannah Price (Records Centre Coordinator)

## Overview

The records centre at Telford holds UK records and the legal archive. Reutlingen records are held in off-site storage operated by our contracted storage partner. Both locations use the same box register, fileroom.

Boxes are sent from Reutlingen and Telford using the standard box number scheme. Each box gets a barcode label printed from the box register; the barcode is what the storage partner scans on receipt.

## Sending boxes in

1. Create a new box entry in the box register. Select the originating site (Reutlingen or Telford) and the retention class. The system assigns the next box number in the site sequence.
2. Print the barcode label (one per box). The label includes the box number, site code, and retention class.
3. Attach the label to the short side of the box, top left corner. Do not cover the existing box number if the box is being reused.
4. For Telford boxes, fill in the transfer sheet and put it in the top box. For Reutlingen boxes, raise a collection request via the supplier portal; the storage partner collects from the Reutlingen loading bay on their scheduled weekly run.
5. Update the box register status to **In transit**. The storage partner or the records centre scans the barcode on arrival and the status changes to **Stored**.

Boxes going to the Telford records centre go via internal mail. Hannah Price coordinates the drop-off times with the Telford plant office — aim to have boxes there before the mid-afternoon mail run.

## Retrieval requests

1. Raise a retrieval request in the box register.
2. Select the box (or individual file within a box, if the file-level index is populated).
3. Choose the delivery method:
   - **Telford records centre** — collection from the records centre, or scan and email for files up to 25 pages.
   - **Reutlingen off-site** — standard retrieval (next working day) or urgent retrieval (same day, before the storage partner's last collection).
4. Submit. The request goes to the Records management team.

Turnaround: Telford retrievals are ready for collection within one working day. Reutlingen standard retrievals arrive at the Reutlingen HQ reception the next working day; urgent retrievals arrive the same day if requested before the storage partner's cut-off.

Records management messages the requester in chat when the box or file is ready. For boxes, the requester signs the box out in the box register. For scanned files, the scan is attached to the retrieval request.

## Box register

The box register shows:

- Box number and site code
- Retention class and keep-until date
- Current status (In preparation, In transit, Stored, Retrieved, Returned, Destroyed)
- Location (records centre shelf, off-site bay, or requester name if signed out)
- Contents summary (free text, populated at the time of boxing)

The register is searchable by box number, retention class, and contents text. Only Records management and selected Legal staff have write access; everyone else has read access.

## If it goes wrong

- **Barcode does not scan** — check the label is not damaged or folded. If it will not scan, print a replacement label from the box register and attach it next to the original. Do not remove the original.
- **Box arrives at the wrong site** — contact Hannah Price. She arranges redirection with the storage partner or internal mail. Update the box register status back to **In transit** with a note.
- **Retrieval not ready on time** — check the request status in the box register. If it still shows **Open**, contact Records management directly. For Reutlingen urgent retrievals, the storage partner's cut-off is fixed; if the request missed it, the box arrives the next working day.
- **Box cannot be found in the register** — search by contents text or contact Records management. Do not create a duplicate box entry.
- **Wrong box contents** — if the contents do not match the register, leave everything in the box, note the discrepancy in the box register, and tell Records management. Do not re-file items yourself.

Fiona Gallagher is the escalation point for register discrepancies. For anything involving the off-site storage contract, contact Owen Hughes's team via the contract register.
