## Adding a page

- Put it under the right department folder; create a new folder if the topic doesn't fit an existing one.
- Title the page, add a one-line description, note the owning team.
- Update this README with the new path and description.
- Ping #southbend-campus or #cork-office depending on where the topic lives. For anything patient-facing, loop in the digital team.
