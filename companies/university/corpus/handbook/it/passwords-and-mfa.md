# Passwords and sign-in

Owner: Information Security. Last edited by Quentin Patel.

## Password manager

- Use the university password manager for every account. If the system supports it, let it generate the password. Do not reuse university passwords anywhere else.
- If a service does not work with the password manager, contact IT Services via the portal and say which system — we keep a list of exceptions.
- Your university account password is not the same as your password manager master password. The master password is the one password you are expected to remember.
- Set up recovery for the password manager (phone number or recovery codes) before you need it. The IT service desk cannot reset a master password.

## Multi-factor sign-in

- Multi-factor sign-in is required on every university account that supports it. This includes the student record system, the VLE, the finance system, the supporter CRM, the library system, the expenses tool, and the room booking system.
- Use the university authenticator app where possible. SMS codes are acceptable for systems that only support SMS, but the app is preferred.
- Hardware tokens are available from IT Infrastructure & Operations for staff who cannot use the app. Ask via the IT service desk portal.
- If you get a multi-factor prompt you did not initiate, reject it. Then report it using the phishing report button in your email client, or via the IT service desk portal marked "security incident". Do not approve the prompt to "see what happens".

## Phishing and suspicious messages

- Report anything that asks you to sign in, share a code, or move money — even if it looks like it comes from a colleague or a supplier. The report button sends it to Information Security.
- If you have already entered your password or approved a prompt, change your password immediately, then report it. Do not wait to see if anything happens.
- Information Security will not ask you for your password or your multi-factor code in chat, email, or by phone. The IT service desk will not either.

## After an unexpected sign-in prompt

- Reject the prompt, change your password, and report the prompt via the portal. That is the whole process.
- If you suspect access to a system that holds student or staff data, mention that in the portal ticket so Information Security can check the sign-in logs without needing to come back to you.
- Keep your device's screen locked when you step away, including in shared offices on Hollins Hill, City campus, and the Kuala Lumpur campus.
