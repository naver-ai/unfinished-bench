# Supplier master data

**Owner:** Accounts payable  
**Last edited by:** Gaurav Harper (Accounts Payable Clerk)

## New supplier request

- [ ] Requester submits the supplier's full legal name, trading name (if different), registered address, and VAT ID via the ERP supplier request screen.
- [ ] Attach a signed bank confirmation letter or the supplier's own headed paper with bank details — plain emails are not sufficient.
- [ ] Supplier must confirm they will invoice us electronically; paper invoices from new suppliers are returned.
- [ ] Requests for non-EU suppliers also go through Trade compliance for the usual sanctions screening before we proceed.
- [ ] Daan Peeters approves the request; Rebecca Klein creates the supplier record. No one else in AP creates suppliers.

## VAT and tax ID checks

- [ ] Validate the VAT ID against the EU VIES database for EU suppliers. Print and attach the check result to the ERP record.
- [ ] UK suppliers: check the VAT registration number format and, where available, confirm against {{COMPANY_REGISTRY_1}}.
- [ ] US suppliers: obtain the W-9 before the record is activated. Keep the W-9 in the finance shared folder, not in the ERP.
- [ ] If a supplier's VAT ID does not validate, the record stays on hold and we ask the supplier for a corrected ID. Gaurav or Julia follow up.
- [ ] Re-validate VAT IDs for existing suppliers during the quarterly supplier review — flag any that no longer match.

## Bank detail verification

- [ ] Bank details are verified by call-back to a known contact at the supplier — use the phone number on file, not one from the new request.
- [ ] Ask the contact to confirm the IBAN (or account and sort code) and the account holder name exactly as printed on the bank statement.
- [ ] Note the call-back on the supplier record, including who spoke to whom. If the contact is not reachable after two attempts, escalate to Daan.
- [ ] Any change to an existing supplier's bank details requires a fresh call-back before the change is saved.
- [ ] Bank details are re-confirmed by call-back whenever we have not paid that supplier for more than a year.

## Duplicate checks

- [ ] Before creating a record, search the ERP by VAT ID, trading name, and postcode. Also search the supplier portal for the same.
- [ ] If a possible duplicate is found, do not merge — flag it to Rebecca and let her decide which record to keep.
- [ ] New records must not be created for a supplier that already exists under a slightly different name; use the existing record and request a name change instead.

## Changes and maintenance

- [ ] Address changes and contact updates are made by Julia Russo or Gaurav Harper.
- [ ] Bank detail changes are made only by Rebecca Klein after verification.
- [ ] Supplier blocking (e.g. for compliance holds) is done only by Daan Peeters.
- [ ] All changes to supplier master data are logged in the ERP audit trail; there is no way to edit without a trace.
- [ ] Inactive suppliers (no purchase order in two years) are reviewed each quarter and flagged for possible blocking — they are not deleted.
